CF Worker 推到公网服务器，本机 WS/HTTP 反拉写入 code_pool。本机无需公网/隧道。 CF Worker 直推本机 /api/webhook/email（可用 CF Tunnel 内网穿透）。少一层服务器中转。 本机 webhook 直收优先，同时保留服务器中转反拉作备份。Worker 通常仍指向本机隧道；服务器桥可作备用入口。

服务器侧 Worker / 备用入口可填：https://你的服务器域名/api/webhook/email

本机直收：保持面板在线；CF Worker 的 EMAIL_WEBHOOK_URL 指向本机可公网访问地址（推荐 Cloudflare Tunnel）。密钥仍用上方 EMAIL_WEBHOOK_SECRET。
